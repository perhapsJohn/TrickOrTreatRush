# Trick or Treat Rush (web build)

The browser build of Trick or Treat Rush, a Halloween push-your-luck party game:
race the street for candy, but only the candy you bring home counts. 1-4 kids on
one screen with bots, or online rooms through the Wayside relay.

Build files only (Godot 4.6 web export). Phones and tablets load `phone.pck`
(touch controls, lighter rendering), everything else `index.pck`; the page picks
one before the engine starts. Played in the Scareathon arcade.
